这份原型演示什么

  • 拖滑块 / 点预设：宽度实时变化，内部是真实 @container 查询 —— 与真机注入层用同一套规则，看到的重排就是实现后的行为。
  • 切功能页签：聊天流 / 审批卡 / 终端 / 文件交付 / 设置 / 市场 / 任务 —— 覆盖 53 个 client-ui 包的主要面。
  • 「手机外壳」「安全区」开关：模拟刘海与 home 条，对应注入层 viewport-fit=cover + env(safe-area-*)。
  • 「适配注释」：叠加标注每处适配点（P0/P1 归属）。

交互行为对应表（点宽度自测）

  • ≤899px：会话列表 → 汉堡抽屉（带遮罩）；文件/终端/交付物 → 底部 sheet 上滑；出现底部 Tab（聊天/文件/终端/更多）；「更多」承接 设置/市场/任务/技能 等低频面。
  • ≤639px：消息满宽；模型/预设 pill 收进输入区；输入框 16px（防 iOS 聚焦放大）；按钮 44px 触控目标；审批卡全宽 + 双大按钮；市场两列卡片；长代码块限高滚动。
  • 桌面 ≥900：三栏原样，零改动 —— 适配层只在代理链路注入，桌面物理隔离。

实现落点（与上一轮 v2 方案一致）

  • 规则载体：admin/mobile-skin.js 静态 CSS，经 reverse-proxy 注入手机侧 HTML（同步改 content-length / 剥 etag / no-store）。
  • 断点机制真机用 @media (max-width:…)（整页视口），本原型为演示用 @container 模拟 —— 规则集相同。
  • 骨架锚点：侧栏/右栏/输入区用 DOM 形状 + --dsw-* token 覆盖，不用构建哈希类名；不命中即静默。
