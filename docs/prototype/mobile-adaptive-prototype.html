v2 交互模型（一句话）

聊天常驻主屏；其余一切都是打开→关闭的覆盖层。会话列表、文件/终端、设置/市场，全部复用宿主已有按钮与路由，适配层没有发明任何新控件。

  • ≤899px 唯一变化：侧栏从「挤占内容」变「滑入覆盖 + 遮罩」，关掉即回主屏。
  • ≤639px 元素级：消息满宽、输入 16px 防缩放、按钮 44px、审批大按钮——纯 CSS。
  • 零 JS 导航：上一版的底栏/抽屉/更多枢纽已删除——那需要注入 JS 造控件，脆且要重新学习。
  • 设置/市场：宿主本来就整页路由，窄屏只是列表/网格自然变窄，无需专门交互。
